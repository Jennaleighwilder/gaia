1. Before you begin

This manual belongs beside the deployment binder. It does not replace county emergency operations plans, USDA award terms, or your IT security policy—it threads them together with the software you were given.

Print this document to PDF (see HOW_TO_PRINT_PDF.md in the same folder) for a bound copy. The styling is meant to be read slowly: headings are set in a traditional serif; instructions stay in clear sans-serif.

2. Who uses what

Role Primary tools
Field lead / crew (e.g. “David”) Field PWA or desktop app: map, GPS, treatments, waypoints, attachments, offline queue.
EOC / coordinator (e.g. “Steve”) Same application with Emergency panel: evacuation zones, road closures, incidents; public feed is read-only elsewhere.
Residents Public map at /public—no login; phone-friendly.
USDA / auditors Exports, match ratio, quarterly reports, spatial layers—unchanged from program requirements.
IT / steward PostgreSQL, backups, TLS, CORS, installer updates—see ADMINISTRATOR_GUIDE.md.

3. The system in one breath

Roads live in the database as geometry tied to a stable ID from the county KMZ—not from a road name alone (names repeat). Treatments, tracks, and waypoints hang off those roads. The API is the truth; phones and laptops are witnesses.

The public portal shows evacuation polygons, closures, incidents, and weather—refreshed on a steady cadence—so a family on a porch road can see what the county posted without an account.

SENTINEL watches corridor risk using weather and fuels logic you configured in the product; it ranks roads so the worst ground shows first—it is a decision support aid, not a siren.

4. Field work (treatments, tracks, waypoints)

4.1 Getting oriented

Pick your road from the selector when you can. The map colors grant corridors and treatment status so untreated grant mileage is visible at a glance.

4.2 Treatments

Log miles, type, contractor dollars, match documentation, and Davis-Bacon flags as your program requires. The Actor field names the human on the audit trail—use a real county id, not “test.”

4.3 Tracks

Record a GPS line when you need to prove where the crew worked. Long tracks cost battery—start and stop deliberately.

4.4 Waypoints & infrastructure

Drop pins for material sites, culverts, guardrails, bridges, and other inventory types your administrator enabled. Condition, inspection dates, and replacement priority support county maintenance planning and CSV export on the API.

4.5 Attachments

Invoices, photos, and PDFs attach to treatments or waypoints. The server stores bytes on disk with a hash—keep filenames sensible; the database keeps the chain of custody.

5. When the sky turns wrong — weather & SENTINEL

The weather card pulls a cached bundle (GAIA first, NOAA fallback). Red Flag warnings raise the visual alarm in the UI. SENTINEL combines that atmosphere signal with ground cues (fuels, drought signals where tokens allow, snowpack where configured) and returns ranked roads.

Remember: SENTINEL informs prioritization. County evacuation orders and ICS structure remain authoritative.

6. Public portal & emergency posting

The resident-facing map lists evacuation levels (1–3 styling), road closures with detour geometry when provided, and incidents. Updates made from the Emergency panel should appear to the public within the refresh window—still verify on a phone before you announce broadly.

Emergency routes require the X-Actor header (the application sets this from the Actor field). Do not expose emergency APIs to the open internet without network controls—see the Administrator Guide.

7. Compliance, exports, and USDA evidence

The match ratio card compares documented match to federal spend using the same rules as the API. Spatial exports and quarterly financial posts exist to feed semi-annual and annual reporting—coordinate dates with your award.

Nothing in this manual changes your grant covenants; the software holds the numbers you enter to the standard you configure.

8. Offline, sync, and the honor of the queue

When service drops, work queues locally. Each operation carries an idempotent client id so the server never double-creates a treatment if a phone retries a flaky connection. Flush when you are online; read errors literally—they usually name the fix (conflict, validation, expired session).

9. Care and keeping (administrators)

9.1 First launch (desktop)

After PostgreSQL is installed and running, open the Ferry County Field System from the Start menu or desktop shortcut. The first-run wizard asks for database host, port, database name, and credentials—use the values your IT team provisioned. If the splash screen shows migration text, wait for success or use Retry after fixing connectivity.

9.2 Where things live on the network

Field staff typically use https://<your-server>/… with the SPA; the API is often at the same host under /api. The public map is usually published at a path such as …/public—your IT sets the exact URL and TLS certificate.

Back up the database and the attachment directory together. Run migrations after backups. Rotate secrets on the schedule your security office sets. For a full checklist, read ADMINISTRATOR_GUIDE.md and DEPLOYMENT.md in this folder.

10. When something breaks

Start with SUPPORT_AND_MAINTENANCE.md: classify severity, confirm whether Postgres is running, and capture exact messages. Escalate with version, OS, and logs—never paste live passwords into email.

Glossary

  • CEMP / grant miles — Program corridor mileage driving treatment eligibility styling.
  • KMZ / KMZ import — Zipped KML road inventory; import establishes geometry and stable IDs.
  • PostGIS — PostgreSQL extension for map geometry.
  • Idempotent sync — Same client operation id → same server result, safe to retry.
  • Public API — Unauthenticated read endpoints for community safety—protect the hosting layer.
