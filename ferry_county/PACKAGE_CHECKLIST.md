# USB / Handoff Package Checklist

Use this list before you **mail a flash drive** or upload a **secure zip**. Check each box.

## Documentation (this folder)

- [ ] `README.md`
- [ ] `SPECIFICATION.md`
- [ ] `DEPLOYMENT.md`
- [ ] `ADMINISTRATOR_GUIDE.md`
- [ ] `SUPPORT_AND_MAINTENANCE.md`
- [ ] `MANUAL.html` (+ printed or PDF via `HOW_TO_PRINT_PDF.md`)
- [ ] `HOW_TO_PRINT_PDF.md`
- [ ] `PACKAGE_CHECKLIST.md` (this file)

## Software artifact (separate file)

- [ ] **Windows installer:** `Ferry County Field System-Setup-<version>.exe` from GitHub Actions **Artifacts** (green **Build Windows installer** run on `main`).
- [ ] Confirm the filename and **date** with the recipient so they know which build they hold.

## Optional (county policy permitting)

- [ ] **`FerryCounty_Complete_Roads_v2.kmz`** — only if redistribution is allowed by your data license.
- [ ] **Connection cheat sheet** — internal only: DB host, non-secret port, database name (passwords **never** on the stick in plain text; use a separate channel).

## Recipient confirmation

- [ ] **Primary contact** name / phone / email filled in on `README.md`.
- [ ] Recipient acknowledges **backup** and **restore** responsibility per `ADMINISTRATOR_GUIDE.md`.

---

*When every box is checked, the package is complete.*
