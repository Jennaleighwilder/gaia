Live road search — Field System

Type a road name in the Field app search bar. The system queries the live database (not a static KMZ file), returns up to ten matches, and when you pick one the map flies there and highlights the corridor in yellow so you see exactly where it is—no more hunting.

What you get

  • Partial name match (case-insensitive) across the county inventory.
  • Grant roads are labeled when CEMP mileage applies.
  • API: GET /roads/search?q=… — same data the map uses.
  • Offline: search needs network; queued work still behaves as before.
For EOC / closures: the emergency panel still uses GET /emergency/roads-search when picking a road for a closure—same idea, trusted context.
